# 🌐 Landing Page – Consultoria em Engenharia Civil

Este projeto consiste no desenvolvimento de uma **landing page profissional** voltada para apresentação de serviços de engenharia civil, com foco em **captação de clientes e autoridade digital**.

---

## 🚀 Acesse o projeto

🔗 [Visualizar repositório no GitHub](https://github.com/MarceloX2115/landing-page-consultoria-engenharia?utm_source=chatgpt.com)

---

## 📌 Sobre o projeto

A landing page foi desenvolvida para representar a marca **Mayra Luanne – Engenheira Civil**, com o objetivo de:

* Apresentar serviços de forma clara e estratégica
* Transmitir credibilidade profissional
* Facilitar o contato com potenciais clientes
* Criar presença digital sólida

Landing pages são amplamente utilizadas para **apresentação de serviços e geração de leads**, sendo uma solução simples e eficiente para presença online ([Aurago][1]).

---

## 🎯 Funcionalidades

* ✅ Layout moderno e elegante
* ✅ Totalmente responsivo (mobile, tablet e desktop)
* ✅ Menu mobile interativo
* ✅ Animações suaves ao rolar a página
* ✅ Scroll suave entre seções
* ✅ Destaque de seção ativa no menu
* ✅ Formulário com validação em JavaScript
* ✅ Botão flutuante para contato via WhatsApp
